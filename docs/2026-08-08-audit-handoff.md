## 1. ⚠️ git 이력을 재작성하고 force push 했다 — 클론을 반드시 새로 맞출 것

696개 커밋 **전체의 SHA가 바뀌었다.** 옛 클론으로 작업하면 다음 두 가지가 일어난다.

- push가 거부되거나(non-fast-forward),
- 억지로 밀면 **제거한 인명이 이력에 되살아난다**(옛 커밋을 다시 올리는 것이므로).

받아오는 법 — 로컬에 **커밋 안 한 변경이 없는지 먼저 확인**하고:

```bash
git fetch origin && git reset --hard origin/main && git reflog expire --expire=now --all && git gc --prune=now
```

커밋했지만 안 올린 작업이 있다면 `git reset --hard` 전에 패치로 빼 둘 것
(`git format-patch origin/main` → 재설정 후 `git am`). 옛 SHA 위에서 리베이스하려 하지 말 것.

**무엇을 지웠나**: 특정 인명이 파일 내용 28개 커밋 · 커밋 메시지 · 파일 경로 2개에
남아 있었다(그 경로는 여기 옮겨 적지 않는다 — 적는 순간 되살아난다).
전부 '기준표'/'ref'로 치환하고 경로도 개명했다. 재작성 후 내용·메시지·경로 **0건**.
저장소가 PUBLIC이고 Pages가 `tools/`·`docs/`까지 서빙하므로 **코드 주석도 서비스 안**이다
— 새 코드에 인명을 쓰지 말 것. 적정물량 표는 **"기준표"**라고 부르고 출처는
국토교통부·한국부동산원만 표기한다.

부수: 커밋 1개에 있던 개인 이메일을 `agongmap@gmail.com`으로 통일했다.

**옛 SHA 참조는 이제 깨졌다.** 커밋 메시지와 문서에 적힌 `716b0bd`·`8954833` 같은
해시는 존재하지 않는 커밋을 가리킨다. 날짜와 제목으로 찾을 것.

## 2. 데이터가 대량으로 교정됐다 — "값이 왜 바뀌었지?"는 버그가 아니다

원인은 하나다. **모든 수집 함수가 '최근 N'만 다시 받고, 그 밖의 과거는 최초 시딩 때
판본이 영구히 굳는다**(`BASIC_MONTHS` 8 / `BASIC_MONTHS_DEEP` 15 / `ANNUAL_YEARS` 3 /
`SUPPLY_MONTHS` 8 / `RECENT_WEEKS` 20 / `RECENT_MONTHS` 14).

| 계열 | 교정 | 무엇이 틀렸었나 |
|---|---|---|
| 전세가율 | 2,593셀 | 2025.03↔04 경계에 두 판본이 이어 붙어 전북에 +8.9%p 인공 절벽 |
| 매매지수 | 6,041셀 | 옛 저장분은 소수 1자리, 원천은 2자리. 서북권 전월비 부호가 뒤집힌 달 있음 |
| 전세지수 | 3,666셀 | 최대 편차 제주 2015.09 저장 92.4 vs 원천 90.56 |
| 보급률 | 186셀 | 2014년까지 **구지표**, 2015년부터 신지표 혼용 → 2015년에 없던 급락(전국 −1.2%p) |
| 주간·월간 시세 | 360행 | **제주가 제주도가 아니라 제주시** 계열(117주 중 88주) |
| 버블밴드 | 재시딩 | **광주가 경기 광주시**(a1525) 값. 5.57 → 5.71 |

**교정 도구가 생겼다. 원천이 소급 정정하거나 지표 정의가 바뀌면 이걸 돌린다:**

```bash
python tools/update_adv_data.py --heal-basic <계열> [개월]    # 월별 기본통계
python tools/update_adv_data.py --heal-annual <계열> [연수]   # 연간 계열
python tools/update_adv_data.py --heal-price [주] [월]        # 주간·월간 시세
```

⚠️ `--heal-annual`은 **조회 범위 밖 연도를 지우지 않는다**. 그 규칙이 없어서
아파트건설 1970~1994년 25셀을 한 번 날렸다(백업 복원). 고치지 말 것.

## 3. 이 저장소가 반복해서 걸리는 결함 세 가지 — 새 코드에서 지킬 것

### ① 갱신창 밖 이력이 굳는다
위 2번. 새 계열을 넣을 때 "과거는 언제 다시 받나"를 먼저 정할 것.

### ② 지역을 이름으로만 키잉하면 시도와 시군구가 충돌한다
같은 이름이 둘이면 **뒤 행이 앞을 덮는다**. 실제 피해: 제주(`c8` 제주도 / `c801` 제주시),
광주(`b3`·`a11` 광주광역시 / `a80404`·`a1525` 경기 광주시).

**규칙: 같은 이름이면 지역코드가 짧은 쪽(상위 행정단위)을 채택한다.**
현재 `_fetch_basic_one`·`fetch_bubble`에 들어가 있다. **새 수집 함수에 같이 넣을 것.**

### ③ 마크업(td↔th)만 바꾸고 CSS를 안 따라간다
한 회차에서만 4건 나왔다. `th`일 때 상위 셀렉터(`thead th{position:sticky}` 등)가
대신 걸어주던 속성이 `td`로 바꾸면 통째로 빠진다. 실제로 홈 표 '적정물량' 수치 20칸이
스크롤하면 사라지고 라벨만 남의 줄에 얹혔다. **마크업을 바꾸면 그 셀렉터를 grep할 것.**

부수 교훈: `role="button"`을 `th`에 주면 `columnheader` 역할이 사라져 열 머리 연결이
끊기고 `aria-sort`도 무효가 된다. 키보드 접근은 `tabindex` + `keydown`으로 충분하다.

## 4. 구조·계약이 바뀐 것

- **`ADV.permits`가 20지역**이 됐다(전국·지방 추가). `ref`(저점·고점)는 이제
  `permit_ref(regions, rows)`가 rows에서 **매번 유도**한다 — 지역을 늘리면 자동으로 따라온다.
  하드코딩된 `ref`를 되살리지 말 것(전국이 기본 선택인데 ref가 없어 색·참조선·각주가
  통째로 사라졌던 원인).
- **`sido_zones.supply_rows`의 미래값은 `round(x, 3)`**이다. 자리수를 줄이면 x.5로 굳어
  소비자의 `Math.round`가 다시 올리는 **이중 반올림**이 된다(1자리로 뒀다가 11칸이 갈렸다).
  화면은 `occFmt()`로 표시 직전에 한 번만 반올림한다.
- **`--seed-sido`가 `ADV.occupancy`도 함께 갱신한다.** 산식을 고치면 홈·통계 탭·/moveins/가
  같이 움직인다. API 키 없이 돈다.
- **통계 탭 표시 규칙 두 가지**(`index.html`):
  - `DS_ZERO = {준공, 착공, 인허가, 분양}` — 원천이 0을 `-`로 주므로 null을 0으로 본다.
    근거: 17시도 합(null→0) == 원천의 독립 '전국' 행이 준공 191/191·착공 186/186·
    인허가 234/234·분양 129/129 전부 일치. **단 계열이 그 지역에서 시작되기 전의 null은
    0이 아니다**(세종은 2012.07 출범). `dsFirst`/`dsV`가 그 경계를 판다.
  - `DS_CUM = {인허가}` — 연내 누계라 '전기 대비'가 아니라 **'전년 동월 대비'**로 견준다.
    flow용 산식을 그대로 쓰면 매년 1월에 -98%짜리 없는 급락이 찍힌다.
  - 미분양은 `DS_ZERO`에 **넣지 않는다**. null=0이 성립하지만 76개 중 73개가 세종 출범
    이전이라, 넣으면 고쳐지는 3개월보다 없던 도시의 0 73개월이 더 해롭다.
- **`/cycle/`의 시세 배열은 이제 생성기 소관**이다(`tools/refresh_cycle_data.py`,
  두 배치에 편입). 손으로 고치지 말 것 — 세 회차 연속 스테일로 걸린 자리다.
  지역 구성이 **수도권·부산·대구·대전**으로 바뀌었다(옛 생활권 4곳은 정의가 사라져 재현 불가).

## 5. 배치가 달라졌다 — 실패 처리가 더 엄격해졌다

- `git pull --rebase`에서 **`-X theirs`를 뺐다.** data.js는 STATS가 한 줄에 170만 자라
  사람이 그 줄을 손대면 봇과 항상 충돌하는데, 옛 설정이 사람 수정을 경고 없이 되돌렸다.
  이제 충돌하면 배치가 **실패한다** — 데이터는 다음 회차가 다시 만들지만 사람의 수정은
  아무도 못 만들기 때문이다. red를 보면 사람 수정을 확인하고 재실행할 것.
- `make_sido_pages` / `make_indicator_pages` / `refresh_cycle_data` 실패가 **exit 1**이다
  (예전엔 `::warning`으로 흡수하고 데이터만 커밋했다).
- `make_sido_pages`가 **준공·착공의 끝 분기가 다르면 중단**한다(H≠lead). 한쪽만 수집된
  회차에 등급이 조용히 바뀌던 것을 막는다. 지역 결측·구성 불일치도 중단 사유다.
- 아티팩트 채택 정렬에 **3순위 키 `ADV.sido.L`** 추가(주간·월간 동률일 때 공급이 뒤진
  러너가 이기던 구멍).
- **IndexNow 핑이 클라우드 배포 경로에 붙었다.** 클라우드 전환 뒤로 어느 경로에서도
  안 돌고 있었다. 키는 설계상 공개값이라 커밋된 키 파일에서 읽는다.
- 커밋 대상(`TARGETS`)에 `cycle` 추가.

## 7. 손대지 않은 것

- 홈 표의 월/분기/연 **모드 간** 표시 합이 1세대 어긋나는 칸. 원장 합은 정확히 일치하고

  (주간표에는 있다). 값이 없는 시군구는 드롭다운에서 자동으로 빠진다 — 원천이 생기면
  자동 복귀. ⚠️ 신설 4구는 옛 중/동/서구의 1:1 후신이 **아니라** 재분할이므로
  옛 계열을 신설 코드에 붙이지 말 것.
