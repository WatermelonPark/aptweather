# PM → 마케팅 세션: 발행 글 등급 라벨 수정 요청 (2026-08-15)

등급 **라벨**이 바뀐다. 산식은 그대로다. 이미 발행한 글 2편에 옛 라벨이 남아 있어 수정이 필요하다.

결정 근거 전문: `docs/2026-08-15-등급컷-결정.md`

## 무엇이 바뀌나

```
  ≥1.5  매우 부족   →  심각한 부족
  ≥1.0  부족        →  매우 부족
  ≥0.5  다소 부족   →  부족
  ≥0.0  균형        →  유지
   <0   공급 여유   →  유지
```

`GRADE_CUTS`는 **손대지 않는다.** 숫자가 바뀐 게 아니라 그 구간을 부르는 이름이 바뀐 것이다.

## ⚠️ 순서가 중요하다 — 사이트가 먼저다

데이터 세션이 라벨을 적용하고 사이트가 재생성된 **뒤에** 블로그를 고친다.
순서가 뒤바뀌면 블로그와 사이트가 서로 다른 라벨을 말하는 구간이 생긴다.
우리가 파는 게 계산법의 투명성이라 그 어긋남이 가장 비싸다.

확인 방법: `https://www.agongmap.co.kr/zone/서울/` 을 열어 판정이 **'매우 부족'** 으로
바뀌었으면 적용된 것이다(현재는 '부족').
