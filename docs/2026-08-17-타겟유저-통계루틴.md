# PM: 타겟 사용자의 통계 루틴 — 리서치와 요청 (2026-08-17)

타겟 사용자 집단(사용자가 속한 부동산 스터디 커뮤니티)은 **매달 같은 공개 통계를
같은 순서로 따라 보는 루틴**이 있다. 그 루틴에서 겪는 불편을 실측했고, 상당 부분을
우리가 이미 풀고 있다는 것을 확인했다. 남은 것은 확인 1건과 배치 1건이다.

⚠️ **표기 규칙.** 이 문서와 후속 작업 어디에도 특정 인물·강의·유료 콘텐츠를 출처로
적지 않는다(저장소 공개, 하드 룰). 아래 불편은 전부 **정부 통계 화면 자체의 사실**이라
출처 없이 검증 가능하다. 우리가 만드는 것은 공개 통계를 보는 화면이지, 누군가의
해석이나 강의 내용이 아니다.

## 리서치 근거

**① 키워드 빈도** — 최근 강의 전사 108편(2026년분, 로컬 비공개 아카이브)에서
통계 주제별 언급 파일 수:

| 주제 | 파일 수 |
|---|---|
| 입주물량 | 82 |
| 금리 | 80 |
| 인허가 | 63 |
| 미분양 | 50 |
| 전세가율 | 48 |

**② 최신 월간 브리핑(2026-08) 실측** — 루틴 순서: **시도별 매매·전세·월세 상세
→ 인허가 물량 → 입주 물량**. 그 과정에서 나온 불편 네 가지(전부 정부 화면의 사실):

1. **발표 시차** — 같은 지표인데 통계청(KOSIS) 화면이 더 보기 편한데 늦게 올라와서,
   불편한 부동산원 화면을 먼저 본다.
2. **행정구역 개편으로 표가 깨졌다** — 광주·전남 통합, 인천 구 분리 이후 정부 화면에서
   **광주 단독 값이 아예 안 나온다.** 구 단위 숫자를 손으로 더해 광주 값을 복원해서
   보고 있다. "도표 맞춰보는 입장이면 되게 불편"한 상태.
3. **권역 묶음 불일치** — 정부 화면의 권역 구분이 보고 싶은 단위와 안 맞는다.
4. **찾기 자체가 어려워짐** — "예전엔 그냥 떴는데 지금 찾기가 복잡해졌다."

## 우리 현황 대조 — 대부분 이미 있다

| 루틴 항목 | 아공맵 | 비고 |
|---|---|---|
| 시도별 매·전·월 | ✅ 통계 시장동향 주간·월간 | 월간에 전세·월세 포함 확인 |
| 인허가 | ✅ 투자지표 (반기별) | 루틴은 월 단위로 봄 — 단위 차이 |
| 입주물량 | ✅ 투자지표 (분기별, 착공 추정 포함) | |
| 미분양 | ✅ 지역 페이지 + 통계 | |
| 전세가율 | ✅ /jeonse-ratio/ | |
| **광주·전남 분리** | ✅ **20개 단위에 둘 다 유지 중** | **정부 화면에는 없는 것** |

**가장 큰 불편(②)을 우리는 이미 풀고 있다.** 정부 화면에서 사라진 광주 단독 값이
아공맵에는 그대로 있다. 이게 이 사용자 집단에 대한 우리의 가장 강한 차별점이다.

## A. 데이터 세션 — 경계 유지 가능성 확인 (중요)

**질문: 원자료가 통합 단위로 발표되기 시작해도 우리가 광주·전남 분리를 유지할 수
있는가?** 지금 분리돼 보이는 게 옛 데이터의 관성인지, 앞으로도 지킬 수 있는 구조인지.

- 국토부·부동산원 발표가 통합(전남광주)으로 바뀌면 어느 시점부터 우리 시계열이 끊기나
- 구·시군 단위 원자료로 옛 경계를 **자동 합산 복원**할 수 있나(사용자들이 손으로 하는
  그 계산을 우리가 대신) — 가능하다면 '기존 경계 기준' 표기와 함께
- 인천 구 분리도 같은 관점에서 점검
- 결론이 "지금은 문제없음"이어도 좋다 — **언제 깨질지**를 알아두는 게 목적이다.

## B. 개발 세션 — 통계 탭 '월간 루틴' 동선

새 지표를 만드는 게 아니다. **이미 있는 것의 배치 문제다.**
매달 발표 직후 "시도별 매·전·월 → 인허가 → 입주물량 → 미분양"을 끊김 없이 한 흐름으로
볼 수 있는 동선이면 된다. 구현 형태(탭 순서 조정이든, '월간 루틴' 진입점이든)는
개발 판단에 맡긴다. 홈 개선 3건과 독립이며 급하지 않다 — A 확인이 먼저다.

## 마케팅 각도 (요청 아님, 기록)

"정부 화면에서 광주 공급량이 사라졌다 — 여기서는 계속 따로 본다"는 콘텐츠 각도가
성립한다. 통계 화면의 사실만 말하면 되므로 출처 규칙과 충돌하지 않는다.
커뮤니티에 직접 알리는 방식과 시점은 대표 판단 영역이라 여기서 정하지 않는다.
