## 처리 결과 (디자인 세션)

요청서의 '빠진 것' 표를 이렇게 메웠다 — 다만 **PNG를 그대로 옮기지는 않았다.**
PNG는 1200×630 고정 캔버스라 제목·요약을 다 넣을 자리가 있었지만, 홈 배너는
반응형이고 위에 섹션 h2가 이미 있다. 같은 목적을 더 적은 요소로 달성했다.

| 집계 3 vs 17시도 구분 | 집계를 격자에서 떼어 상단 블록(숫자 20px)으로. 홈 지도 집계 칩과 같은 구조 |
| 카드 안 위계 | 지역명 11px·500·muted / 매매 15px·700 / 전세 10.5px·muted |

### 데이터 쪽에 알릴 것 (개발 세션 확인 요망)

**`fmtPct`가 −0.00을 찍고 있었다.** 부산 원값 −0.0012가 화면에 `−0.00`으로
나왔다(실측). 배너는 감사 세션 정본 `pv2`/`pvSign`으로 갈아탔고 0.00은 무색·
부호 없음으로 떨어진다. **`fmtPct`를 쓰는 다른 자리가 있으면 같은 증상이 있을
수 있다** — 확인 부탁한다.

## 무슨 일이 있었나

홈 주간 시세 배너에 `share/weekly-map.png`(1200×630, 카톡 공유용)를 그대로 걸었다.
**고정 비율이라 폭이 좁아지면 글자가 뭉갰다** — 사용자 지적. 그래서 같은 격자를
HTML로 다시 그렸다(`b6430b3`). 반응형은 해결됐는데(320px 2열 / 375px 3열 /
1280px 3열, 넘침 0) **PNG가 갖고 있던 디자인을 옮기지 않았다.** 값만 옮겼다.

## 지금 상태 — 무엇이 빠졌나

`index.html`의 `renderWeeklyGrid()` + `app.css`의 `.wgrid / .wg-head / .wg-cells / .wc`.

PNG에는 있는데 HTML에는 없는 것:

| 범례 칩 — 🔴 상승 / 🔵 하락 | 없음 |

즉 **정보는 다 있는데 읽는 순서가 없다.** 20칸이 균질하게 깔려 있어 눈이
어디부터 볼지 모른다. PNG는 제목 → 범례 → 격자 → 요약으로 시선을 끌고 갔다.

## 요청

위 격자의 **시각 설계**를 맡아 달라. 마크업·CSS를 바꿔도 되고, 렌더 함수 구조를
바꿔야 하면 알려주면 개발 쪽에서 맞춘다.

지켜야 할 제약:
- **반응형이 목적이었다.** 고정 비율·고정 폭으로 되돌리지 말 것(320px에서도 안 깨져야 한다).
- 값은 `ADV.weekly.rows`(시도 20곳, `regions`와 같은 순서)에서 읽는다. 데이터 추가가
  필요하면 말해 달라 — `split_data`가 코어에 싣는 범위를 넓히면 된다.
- 격자선은 **셀이 `box-shadow`로 그린다.** 컨테이너에 `background:var(--line)`을
  깔면 마지막 줄 빈 칸에 선 색이 덩어리로 드러난다(`test_grid_line_trick`이 막는다).
- 색은 홈 지도와 같은 문법 — 상승 빨강(`#a93226`) / 하락 파랑(`#1a5276`).
- 디자인 시스템(원부/장부 조판)을 따른다: 800 웨이트·골드·accent 금지, radius 2값,
  쿨 색토큰. `tools/audit_design.py`가 검사한다.
