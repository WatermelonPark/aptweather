## 1. Actions Node.js 20 지원 종료 경고

**증상.** 데이터 자동 갱신 워크플로 실행마다 경고가 붙는다:
`actions/upload-artifact@v4`가 Node.js 20을 타겟으로 하는데, GitHub이 2025-09-19부로
Node 20 지원 종료를 예고하고 러너가 강제로 Node 24로 올려 돌리는 중이다.

**왜 백로그인가.** 지금은 경고일 뿐 배치가 정상 동작한다(2026-09-09 점검에서 확인).
다만 GitHub이 강제 실행을 끊는 시점이 오면 **데이터 배치가 통째로 멈춘다.**
그날 고치면 늦다 — 주간 갱신이 하루 이틀 빠지는 걸로 끝나지 않을 수 있다.

**할 일.** 워크플로들의 `actions/upload-artifact`(그리고 같은 경고가 붙는 액션이 있으면
함께)를 Node 24 대응 버전으로 올린다. 올린 뒤 실제 배치 1회가 성공하는 것까지 확인.

**확인 방법.**
```bash
gh run list --limit 5
gh run view <run-id>   # ANNOTATIONS에 Node.js 20 경고가 없어야 한다
```
