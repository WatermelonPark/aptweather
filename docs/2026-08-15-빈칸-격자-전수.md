## 1. `.zlinks` — 이번에 고칠 것

**증상.** `/zone/<지역>/` 하단 「다른 지역」 격자의 오른쪽 아래 마지막 칸이 회색 덩어리로 남는다.
5열에 항목이 19개(집계 3 + 시도 16, 자기 지역 제외)라 마지막 줄에 한 칸이 빈다.

**현재:**
```css
.zlinks{display:grid;grid-template-columns:repeat(auto-fill,minmax(150px,1fr));gap:1px;
  background:var(--line);border:1px solid var(--line);margin-top:12px}
.zlinks a{background:var(--paper);padding:10px 12px;text-decoration:none;color:var(--ink);
  display:flex;align-items:center;gap:7px;flex-wrap:wrap;font-size:13.5px}
```

**고칠 방향 — `.zgrid`에 이미 적용한 것과 동일하게.** 참고로 그쪽은 이렇게 됐다:
```css
.zgrid{display:grid;...;gap:1px;margin-top:14px}                    /* background·border 제거 */
.zcell{background:var(--paper);padding:13px 14px;box-shadow:0 0 0 1px var(--line)}
```
`.zlinks`도 컨테이너의 `background`·`border`를 걷고 `.zlinks a`에 `box-shadow:0 0 0 1px var(--line)`를
얹으면 빈 자리가 생기지 않는다. **다만 최종 판단은 개발 쪽에 맡긴다** — hover 배경(`--paper2`)과
겹칠 때 선이 어떻게 보이는지는 실제로 띄워봐야 안다.

## 2. `.map-agg` — 확인만

675행이 같은 트릭인데 `display:flex`다. flex는 남는 칸이라는 개념이 없어 문제가 안 생기는 게
보통이지만, 항목이 줄바꿈될 때 뒤쪽 여백에 선 색이 드러나는지는 **확인이 필요하다.**
문제없으면 그대로 두면 된다 — 굳이 손대지 말 것.

## 3. 재발 방지 — 이게 본 요청의 핵심이다

같은 결함이 **두 번 나왔다.** 세 번째를 막는 장치를 함께 넣어주기를 요청한다.

`display:grid`와 `background:var(--line)`가 같은 규칙에 함께 있으면 실패하는 테스트 한 줄이면
충분하다. 그리드는 셀이 없는 자리를 컨테이너 배경으로 드러내므로, 이 조합 자체가 결함
신호다(flex는 예외로 두면 된다).

없으면 다음에 누가 새 격자를 만들 때 같은 방식을 또 쓴다. 실제로 그렇게 됐다.
